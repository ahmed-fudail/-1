# دليل مراكز التكلفة - الواجهة الزجاجية

واجهة ويب عربية متجاوبة تعمل محليًا، تعرض البيانات في بطاقات زجاجية وتوفر بحثًا ذكيًا ومشاركة تفاصيل كل سجل.

## التشغيل

من داخل مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المزايا

- 22 سجلًا أساسيًا مضمّنًا.
- بطاقات متجاوبة للهاتف والكمبيوتر.
- بحث عربي وإنجليزي مع تطبيع الأرقام والفواصل والمرادفات.
- ترتيب النتائج حسب قوة التطابق.
- مشاركة البطاقة عبر Web Share API أو نسخها للحافظة.
- تصفية السجلات حسب حالة المراجعة.
- معالجة تواريخ الملاحظات المصححة مع الحفاظ على الرموز التشغيلية.

- شعار الشركة مدمج داخل الواجهة مع حركة CSS هادئة وتأثير إضاءة دائري.
- ظهور تدريجي سلس لبطاقات النتائج مع احترام إعداد تقليل الحركة في النظام.

- شاشة تحميل متحركة تظهر عند التحديث لمدة تقارب ثانيتين قبل دخول الصفحة.
- أربعة ثيمات زجاجية، مع حفظ الثيم المختار في LocalStorage واستعادته تلقائيًا.

## ثيمات V2.5 العملية

- فاتح احترافي: مناسب للاستخدام اليومي والطباعة والبيئات المكتبية.
- داكن مريح: تباين هادئ للاستخدام الليلي.
- أزرق مؤسسي: طابع رسمي ومتزن.
- رملي هادئ: ألوان دافئة منخفضة الإجهاد البصري.
